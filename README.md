## 📌 Repository Overview

This repository contains the **Python programming assignments and practical exercises** completed as part of my **On-Job Training Program at Bassetti India Pvt. Ltd.**

The repository documents my progression from **Python fundamentals and collection operations** to **function-based application development, modular programming, validation, exception handling, and command-line applications**.

The assignments are designed to strengthen programming fundamentals through hands-on implementation, logical problem solving, and progressively structured application development.

---

## 🎯 Training Objectives

The primary objectives of this training are to:

* Strengthen Python programming fundamentals
* Develop strong understanding of Python's built-in data structures
* Improve logical and problem-solving abilities
* Work with nested and complex data structures
* Understand and implement recursion
* Develop reusable solutions using functions
* Understand modular programming and code organization
* Implement input validation and exception handling
* Apply business rules to practical applications
* Build interactive command-line applications
* Develop clean, readable, and maintainable Python code
* Establish a strong foundation for Object-Oriented Programming and backend development

# ▶️ Running the Assignments

Clone the repository:

```bash
git clone https://github.com/alindapal07/Bassetti_India_Pvt_Ltd_ON-JOB-TRAINING.git
```

Navigate to the project:

```bash
cd Bassetti_India_Pvt_Ltd_ON-JOB-TRAINING
```

Run an individual assignment:

```bash
python Assignment_03/swapping.py
```

For Day 02 applications:

```bash
python "DAY-2/Function Only/02 Calculator Module/main.py"
```

Or:

```bash
python "DAY-2/Function Only/CLI LIBRARY MANAGEMENT SYSTEM/main.py"
```
