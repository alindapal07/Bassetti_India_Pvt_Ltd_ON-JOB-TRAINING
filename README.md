Bassetti India Pvt Ltd - On-Job Training
This repository contains my Python programming assignments completed during the On-Job Training program at Bassetti India Pvt Ltd.

The assignments mainly focus on Python collections, nested data handling, recursion, dictionary operations, set operations, and basic problem-solving.

Assignments
Assignment 01 - Python Collections
Exploration and coding examples of commonly used methods and operations for:

List

Tuple

Set

Dictionary

Files:

Assignment_01/List.py

Assignment_01/Tuple.PY

Assignment_01/set.py

Assignment_01/dictionary.py

The examples cover commonly used methods such as append(), extend(), insert(), remove(), pop(), clear(), index(), count(), sort(), reverse(), copy(), get(), keys(), values(), items(), update(), setdefault(), union(), intersection(), difference(), and other frequently used collection operations.

Assignment 02 - Custom Deep Copy
Created a simple custom version of Python's copy.deepcopy() method without directly using the built-in deepcopy() function.

File:

Assignment_02/copy.deepcopy.py

The program handles nested dictionaries, lists, tuples, and sets by recursively copying their contents.

Assignment 03 - Swap Two Variables
Swaps the values of two variables without using a third variable.

File:

Assignment_03/swapping.py

Assignment 04 - Set Operations
Demonstrates commonly used set operations and methods.

File:

Assignment_04/set_operation.py

The program covers:

Union

Intersection

Difference

Symmetric Difference

Set update operations

Subset

Superset

Disjoint sets

Adding and removing elements

Assignment 05 - Dictionary Flattening
Converts a nested dictionary into a flat dictionary using a user-defined separator.

File:

Assignment_05/dictionary.flattening.py

Example:

Input:
{"a": 10, "b": {"c": {"d": 20}}, "e": 100}

Separator:
.

Output:
{"a": 10, "b.c.d": 20, "e": 100}
The program is implemented using recursion, so it can handle dictionaries with multiple levels of nesting.

Assignment 06 - Sum of Numbers in Nested List
Finds the sum of all integer and floating-point values present inside a nested list.

File:

Assignment_06/sum_In_Nested_List.py

Example:

Input:
[10, 20, "Test", None, 3.2, [10, [40, [60, [90]]]]]

Output:
233.2
The program uses recursion to search through nested lists and add all numeric values.

How to Run
Clone the repository:

git clone https://github.com/alindapal07/Bassetti_India_Pvt_Ltd_ON-JOB-TRAINING.git
Move into the project folder:

cd Bassetti_India_Pvt_Ltd_ON-JOB-TRAINING
Run any assignment file using:

python Assignment_03/swapping.py
For programs that take user input, enter the required values when prompted.

For example:

python Assignment_05/dictionary.flattening.py
